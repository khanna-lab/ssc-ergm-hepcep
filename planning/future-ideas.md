# Future Ideas

Notes for later, longer versions of the workshop — not for the SSC 2026 delivery.

## Module 1 — network diagrams

The side-by-side observed vs. simulated network plots are hard to compare by eye
(force-directed layout is arbitrary). For a future talk, break the structure down
more fully:

- **Fixed layout:** lay out the observed network once and reuse those coordinates
  for the simulated draw, so only the ties differ — makes the two visually comparable.
- **Zoom to a mechanism:** show a subgraph or ego-network colored by grade, so
  clustering is legible instead of a whole-graph hairball.
