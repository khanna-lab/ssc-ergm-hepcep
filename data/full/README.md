# Full HepCEP Dataset

This directory is a placeholder for the full HepCEP PWID network dataset.

The workshop uses a synthetic n=1000 dataset in `data/synthetic/` that mirrors the structural properties of this data.

To access the full dataset for post-workshop exploration, contact the workshop organizers:
- Aditya Khanna (aditya_khanna@brown.edu)
- Jonathan Ozik (jozik@anl.gov)

The full pipeline for fitting ERGMs to this data is available at:
https://github.com/hepcep/net-ergm-v4plus
